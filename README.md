# 핀톡 (FinTalk)

국내 주식, 미국 주식, 암호화폐 투자자들이 자신의 분석과 생각을 공유하고, 양질의 콘텐츠로 가치를 창출하는 금융 커뮤니티 플랫폼입니다.

## 메뉴

| 메뉴 | 경로 | 설명 |
|---|---|---|
| 홈 | `/` | 플랫폼 소개, 이번 주 인사이트, 시장 전망·리워드 요약, 커뮤니티 피드 |
| 커뮤니티 | `/community` | 게시판·종목 태그(`?ticker=`)별 게시글, 댓글, 추천 |
| 인사이트 | `/insights` | 추천을 많이 받은 분석 글과 인기 분석가 |
| 시장 전망 | `/outlook` | 상승·하락 전망 참여와 투자자 심리 |
| 리워드 | `/rewards` | 내 콘텐츠 성과와 리워드(수익 공유는 준비 중) |

이전 주소(`/news`, `/market`, `/challenges`, `/creators/dashboard`)는 새 메뉴로 리다이렉트됩니다.

## 개발

```bash
npm install
npm run dev
```

환경변수는 `.env.example` 을 참고하세요. Supabase 설정은 `docs/SUPABASE_SETUP.md` 를 참고하세요. 환경변수가 없으면 샘플 데이터 모드로 동작합니다.
